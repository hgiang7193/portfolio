## Run locally

No build step or package installation needed. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/hgiang7193/portfolio.git
cd portfolio
```

For a better local-development experience, serve the folder with VS Code's **Live Server** extension.
